# 手工 QA 清单

以下动作可安装后在独立窗口中复验。自动化实测项目和时间戳见同目录的验收报告及 JSON。

- [ ] 启动并检查菜单栏 ♧ 和透明角色，Dock 没有新图标。点击角色能打开聊天；点击帽檐外、裙摆旁的透明区域能操作下面的普通窗口。
- [ ] 将角色拖到屏幕两侧并甩动，确认墙面及地面反弹、停稳、位置持久化。接上第二块显示器，分别拖到不同缩放比例、负坐标屏幕和 Dock 所在屏幕。拔掉第二屏后确认角色回到可见工作区。
- [ ] 新开真实的 Codex 任务，依次观察思考、执行、完成、待机；点击气泡回到原 thread。让两个 thread 同时有任务，结束其中一个后，另一个仍有状态。
- [ ] 在正常需要人工批准的任务中核对等待表情和系统通知。先审阅对应 hook，保持原本权限策略。中断一个回合后检查 idle；让工具返回错误而 Codex 能继续修复时，工作详情应继续。
- [ ] 连续对话两轮，再中断第三轮。重启后已完成两轮还在。清空、重启后记忆为空。
- [ ] 开启碎碎念，设五分钟、当前不在安静时段并保持空闲，等待一句话。打开专注或静音，一个完整间隔内应安静。测试后可恢复 45 分钟或关闭。
- [ ] 启用系统通知授权，打开相应语音开关，在可听音量下核对播报；静音后不应发声。检查不同通知权限下的气泡体验。
- [ ] 修改大小、角色、人设、映射和唤醒键。收起窗口后复查绘图停止，重新打开后恢复。
- [ ] 在另一份档案里聊天，再回主档案检查记忆各自独立。在主档案运行时安排一项 1 分钟后的 MCP 提醒，点击通知跳回关联会话，并完成提醒观察庆祝。
- [ ] 开启过账户同步时，使用菜单切回原宠物，再切回独立伙伴。卸载前如要保留个人记忆先备份；执行卸载后检查本插件、缓存、独立应用和私有目录都已移除。原宠物图集仍可用。若安装期间手工改过其他 Codex 设置，确认它们保留。
- [ ] 长稳数据以墙钟和同一对进程为准。关闭自己的测试副本后运行 `scripts/soak.py 3600`，保持主伙伴进程连续运行一小时。长稳中断后应重新计时。

## 2.1 桌面手感

- [ ] 将指针放在人物脸或衣服上，观察卡片的工具、耗时、计划。在空闲和存在 update_plan 的任务中分别验证。
- [ ] 人物身上右键。依次点「骑士礼」「点播动作 → 风与潮 → 祈愿水环」「待办事项」「睡觉」。睡着时再单击叫醒。
- [ ] 慢拖到屏幕中央，停一下并释放。按住角色快速画一个小圈、松手；再试左右快速来回拖，检查两种手势都能飞离释放点并与侧墙反弹。快速直线拖动仍朝拖动方向飞出。双击并在第二击持续拖动，确认释放后向拉动的反方向飞行。
- [ ] 从其他应用直接单击人物，立即打字并回车，观察贴在人物头顶的回复。移动人物后检查待办与气泡仍跟随。用「聊天记录」查看、朗读或删除一轮。
- [ ] 在有第二台显示器、支持听写的麦克风、支持运动传感器的移动浏览器时，分别检验跨屏、按住转文字和传感器手感。

- [ ] 在 macOS 应用列表检查卡提头像。退出该应用后点图标打开设置，关设置后再点图标应在同一进程再次弹出。用两个不同情绪的回复观察对话插画和随机动作，长回复能够滚动。

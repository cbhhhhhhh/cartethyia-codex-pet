# 2.1.1 应用列表图标修复

2.1 的 ICNS 可以在 Finder 文件行显示，但本机 macOS 系统「应用」的默认网格与 LaunchOS 搜索结果仍显示通用白色占位图。2.1.1 显式声明图标资源名称和 Info.plist 版本，并在安装器复制、验证完正式包后更新包目录时间，重新注册该应用并请求 Spotlight 导入。应用包继续使用原来的 bundle ID。

本机重新打开 LaunchOS，核对了按名称筛选的应用图标；在系统「应用」中分别核对了搜索结果和重新载入后的默认网格；在 Finder 中核对了已安装应用被选中时的实际文件行。下面三个图块直接截自这些运行中的界面。桌宠与原 Codex 应用均已通过严格签名验证。

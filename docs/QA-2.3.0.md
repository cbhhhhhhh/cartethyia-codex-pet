| 验收项 | 实测结果 |

| 中断、审批与失败 | 中断到 idle 为 17 ms，审批到等待动作为 32 ms，JSONL 的任务错误到失败动作为 198 ms。强制结束隔离测试的 broker 后，角色回到待机并重新连接。 |

| 命中、拖拽与甩出 | AppKit 窗口事件验证了透明像素穿透、实体像素响应、停在半空、画闭合圈甩出、侧墙反弹和地面摩擦。双显示器的拼接与间隙以几何测试覆盖，实测机连接一块物理屏幕。 |

### Ultra/Fast 子智能体案例

通过当前登录的 Codex 账户，在隔离目录用 `gpt-6.2-sol`、Ultra 推理和 priority 服务档运行算术任务。一个主任务同时派出两个子智能体，同时运行另一个独立主会话。两个子智能体先结束，原主任务随后又执行了一次工具调用。

| 最终安装版所用代码 | 核对结果 |
| --- | --- |
| 完成气泡 | 子智能体 **0** 次，两条主会话分别 **1** 次 |
| 分叉历史 | 跳过 **37** 条带新时间戳的继承记录 |
| 本轮主会话 | **93,368** tokens |
| 两个子会话 | **16,158** 和 **16,223** tokens，分别与对应源记录相符 |
| 工作任务合计 | **125,749** tokens，与独立从源记录计算的结果一致 |

桌宠自己的模型请求另行记录。账户接口返回的七天周期在界面上显示为「7 天额度」。这次官方查询没有给出该会话的积分或美元金额。本地接口样例另外验证了三个金额字段的单位换算、真实的零、缺少起点时的提示。账户周期百分比和单个工作任务的 token 各用各自的数据源。

## 角色、聊天和碎碎念

- 109 个动作各有一条独立透明 WebP 帧条、四个不同的关键姿势和 24 帧。对全部 2,616 帧解码并比较像素，每段至少有 20 个不同画面，其余为有意的动作停顿。把动作名称遮住，在近似桌宠的大小逐项检查后，重新制作了魔方、护帽、睡眠、点心等 32 段的关键姿势。这是本次制作过程的自查。[32 段重绘动作的关键帧](qa/2.3.0/refined-poses.jpg)
- 原生窗口会实际播放所选片段，点播横步改变了桌面坐标。行礼时触发了短台词，聊天过程中新的动作和工作通知遵守气泡优先级。十张配图显示真实缩略图，手动点图后的发言和随后要求重看的回复都保留所选图。[实际动作预览](v23-actions.gif) · [原生窗口的行礼气泡](qa/2.3.0/action-cue.png)
- 本地 Qwen、兼容 API 和 Codex 三条线路都在主任务仍运行时验证了普通回复纯文字、地名与天气规则、选择配图、收到流式文字后中断，以及取消的回复不写入历史。其中 API 使用实现同一协议的本地 HTTP 测试服务，Codex 使用真实账户和合成问题。另用本地模型验证多轮记忆、跨重启保留、清空和角色隔离。
- 碎碎念在实际计时的间隔内测试了静音、专注与空闲三种情况。允许发言时生成一条，由节流规则阻止立即重播。点击配图也会调用对应碎碎念模型。点播动作台词从为该动作写的短句里挑选。

## 安装、性能与一小时长稳

空白用户目录从发布 ZIP 成功安装仅事件与完整本机推理，文字和可选视觉模型都完成了实推。依次安装 2.2.0 → 2.3.0 → 2.2.0 → 2.3.0，测试档案的设置和聊天逐字节保留。卸载后移除桌宠应用及其私有目录，恢复原 Codex 配置。真实 Mac 保留已升级的桌宠，Codex 配置与升级前逐字节相同，两款应用的代码签名都通过系统验证。

安装器预热后的原生 hook 在独立 Unix socket 上测量。首次 8.14 ms，后续 62 次中位数 5.53 ms、P95 9.10 ms、最长 27.26 ms。另开可见的默认窗口，启用自主动作，在隔离空闲档案按 CPU 时间差测了 144.59 秒，GUI 与 broker 合计平均 **1.529%**，RSS 峰值 **115.33 MiB**。本地 GGUF 推理进程按需启动，其模型内存另计。

**最终安装包连续运行 3600.06 秒。** 真实 Mac 在 18:35:57 启动发行版，按约 30 秒间隔取得 121 个样本，全程为同一桌宠和 broker。预热后两者的 RSS 中位数为 **105.92 MiB**，峰值为 **131.64 MiB**。前、后十分钟的中位数分别为 109.94 和 103.98 MiB。开始与结束时 Apple `leaks` 对两个进程均报告 **0 个泄漏、0 字节**。

在第 0、15、30、45、60 分钟各跑一次 Codex CLI 回环任务，**5/5 成功**，耗时中位数 1.70 秒，最慢 2.04 秒。这个探测覆盖 CLI 任务的往返时延。实际 AI 服务和网络响应时间另计。主实例在预热后的采样点都处于工作状态，其中 3,035.92 秒的 CPU 时间差测量为 **0.868%**。上方的 **1.529%** 来自单独的可见窗口待机测试。

37 项 Python 单元与回归测试通过。报告中的测试答案和动作均来自隔离档案。机器可读记录只包含计数、时延、状态与验证结果。[验收数据](qa/2.3.0/results.json) · [一小时逐次取样](qa/2.3.0/stability-samples.json) · [手工复验清单](MANUAL-QA.md)

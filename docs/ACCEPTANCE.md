# 本机验收

当前安装版的画圈、应用入口和一小时测量见 [2.1 验收](DESKTOP-V2.1.md)。2.0 的交互验收和测量在 [桌面版 2.0](DESKTOP-V2.md)。本页的两小时峰值、累计 CPU 和卸载数据归属于 1.0。

环境为 M4、macOS 27.2.1、ChatGPT.app 26.1117.41037 和 Codex CLI 0.171.0-alpha.13。原生测试调用生产 NSPanel、图集、事件处理、移动物理及聊天代码。涉及模拟输入的行在表中标明。

| 验收 | 已取得的证据 |
| --- | --- |
| 开始和结束小于 1 秒 | 真实 Codex CLI 在隔离 home 使用仅回环的模型 fixture，产生自己的任务日志。由日志记录时间计至窗口绘制，开始 179 ms，结束计入庆祝后回 idle 为 711 ms。[原生测量](native-qa.json) |
| 中断、报错、审批 | 测试窗口输入标准 hook 或错误记录，实测 Interrupt 到 idle 7 ms，无 call ID 的 PermissionRequest 到 waiting 7 ms，JSONL 回合错误到 failed 303 ms，随后自动回 idle。实际桌面递送审批需用户信任插件 hook。[实测](native-qa.json) |
| 拖甩和穿透 | 生产鼠标处理器通过注入的 AppKit 鼠标事件，真实窗口移动、墙/地面反弹、摩擦停稳。透明及非透明像素触发了真实 NSPanel 的相反鼠标接收属性。测试机当时有一块屏幕；第二块物理屏和手感列入手工复验。[实测](native-qa.json) |
| 聊天、记忆、中断和人设 | 真实推理与 broker 管道测试得到修改后的人设名「露米」，下一轮答出「雪团」。中断流式回复后只保留已完成轮次，重新启动、独立档案与清空均通过。[对话测试](conversation-qa.json) · [流式样本](integration.json) |
| 碎碎念 | 单元测试覆盖频率门槛、跨午夜安静时段、工作、静音。实际等待 338.6 秒。到点静音及专注期间均被抑制，解除后收到一次真实本地生成的闲聊，短期无重复。[实测](whisper-qa.json) |
| 设置和重启 | 调整大小和人设后窗口立即变化；在独立新进程重新加载，窗口高度及人设均与设置一致。收起窗口后绘图和命中测试定时器均已停用。[实测](native-qa.json) |
| 卸载恢复 | 走真实卸载、重新安装两阶段。原配置和图集哈希一致，插件缓存及独立应用/支持目录消失，ChatGPT.app 深度严格签名验证通过。Pets 官方接口确认已恢复原 ID。之后重新启用了独立版。[回滚记录](rollback.json) |
| 两小时稳定性 | 同一 GUI 与 broker 连续运行 7200.07 秒，241 次采样，9/9 次隔离本机 Codex 回合完成。启动和结束时系统 leaks 对两进程均报 0 块、0 字节。预热后合计 RSS 中位 100.23 MiB，峰值 139.03 MiB。[汇总](stability-summary.json) · [原始采样](certified-soak.json) · [Codex 探测](cli-probes.json) |

空闲性能采用两个进程的累计 CPU 时间差除以墙钟时间。6313.53 秒可判定连续空闲的区间中，加权均值 1.125%，30 秒区间 P95 为 1.596%，最高 4.957%。平均值和 P95 低于 2%，个别区间超出。ps 单点读数的最高值为 10.3%。前十分钟与后十分钟 RSS 中位数分别为 123.56 和 85.84 MiB。独立推理进程在对话期间会额外加载模型，此数值只衡量常驻桌宠及事件服务。[累计 CPU 测量](idle-cpu.json)

9 次探测各使用时长固定的本机模型 fixture，端到端中位数为 1.70 秒、最长 1.71 秒。这能验证 Codex 在采样点持续响应。桌面应用的交互帧率没有连续采集。

原生命令经过预热后的 62 次进程启动、读取、投递及退出，中位 3.61 ms、P95 4.47 ms、最大 6.76 ms。此次新编译临时二进制冷启动为 294 ms，早期临时构建还观察到约 1.2 秒。安装器在注册前预热，所有 hook 声明异步，发送使用非阻塞 socket；冷启动和系统调度无法承诺 50 ms 硬上限。[hook 测量](hook-benchmark.json)

22 个单元和服务测试通过。另在独立窗口运行工具时终止其 broker，窗口回 idle，服务重启后可接收新回合。两组纯色测试图经本地 Qwen3-VL 得到 red 和 blue。系统中文 TTS 生成了 25,604 个音频帧，测试没有播放声音。[故障恢复](recovery-qa.json) · [图片](vision-qa.json) · [语音](tts-qa.json) · [MCP 注册及真实调用](mcp-qa.json)

系统通知权限与扬声器音量由用户环境控制，未通过目测通知中心横幅或听测音箱作验收。审批测试覆盖收到事件后的实际窗口行为。设备触摸板倾斜、公开插件市场发布、全系统自动读取专注模式均未交付。配套 [手测清单](MANUAL-QA.md) 可复核实际桌面体验。

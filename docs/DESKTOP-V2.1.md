# Cartethyia 2.1

## 直接使用

在应用列表点带卡提头像的 **Codex Pet Plus**。首次打开会显示设置，再次点击能找回已关掉、最小化或被其他窗口盖住的设置。安装器后台启动桌宠时保持桌面安静。**⌃⌥P** 仍可收起或唤出角色。

按住卡提的身体，快速画一个小圈，或快速左右摇两下，松手后她会往随机一侧弹出。慢拖到想放的位置，停一下再松手，可以把她留在半空。沿一个方向快速松手仍会向该方向抛出。实际设置中的「甩出力度」会缩放飞行初速。

单击角色，在她身边输入并回车。气泡上方会出现表情插画，文字使用本机的娃娃体。流式输入期间使用思考神态，完成后根据模型返回的情绪替换插画，并从对应动作中随机选择，连续对话时避开刚播过的动作。工作状态优先展示真实任务动作。悬停工作卡同时保留工具、耗时和计划进度，角色面部随状态变化。以下为实际原生窗口截图，右侧使用了名为 demo 的测试工具。

![本地模型回复与悬停任务卡](v21-preview.png)

插画分为平静、开心、好奇、专注、难过五组，每组两张，来自本机已有卡提角色原画。可在 [十张插画](../src/web/portraits) 查看。自定义角色会使用自己的精灵帧绘制气泡。包内的多尺寸 ICNS 来自同一角色，实际 Finder 图标见[预览](v21-icon.png)。

## 清理和卸载

本机已替换旧的 2.0 可执行应用，并清除了被 Spotlight 收录的 1.0 回退副本。原 Codex 配置、原角色描述、图集和个人聊天／记忆文件在升级前后的 SHA-256 一致。桌宠启动会重新序列化本地设置，等值配置的冷启动复验见上表。完整卸载或切回 Codex 内置宠物的操作见[安装说明](GUIDE-macOS.md#安装和回滚)。

## 一小时稳定性

正式安装的 2.1 连续运行 **3,600.06 秒**。每 30 秒检查桌宠和事件服务，121 次采样中始终是同一对进程。5 次隔离本机 Codex 测试回合全部完成，单次耗时 1.654–1.708 秒。开始和结束时，macOS 的 leaks 工具对两个进程均报告 0 块、0 字节。[稳定性汇总](v21-stability-summary.json) · [逐次回合](v21-cli-probes.json) · [初始泄漏检查](v21-initial-leaks.json)

全程两个常驻进程的合计内存峰值为 **156.22 MiB**，启动一分钟后的中位数为 **126.70 MiB**。累计可判定空闲 1,803.67 秒，平均 CPU **1.70%**，30 秒区间 P95 为 2.43%，最高 2.93%。平均值低于 2%，部分空闲区间超过 2%。按需启动的本地推理模型另计。[逐次采样](v21-soak.json) · [空闲 CPU](v21-idle-cpu.json)
